## Topics Discussed That I Know Very Well
 * HTML Elements: These are the building blocks of web pages, defining the structure and content such as headings, links, and images. Each of these elements are enclosed in tags like "p" for paragraphs and "a" for hyperlinks.

 * HTML Attributes: These provide additional information about HTML elements, helping in defining their behavior or appearance. These are written within the opening and they usually come in name/value pairs.

 * JS Syntax Overview: The set of rules that defines how programs are written and are interpreted in JavaScript. These includes the use of variables, operators, and the use of semicolons to end statements and many more.

 * Arithmetic Operators: The use of these were introduced to us prior to our use of C++ last school year. The function of arithmetics in JS is that they're used to perform mathematical calculations like modulo division and exponentiation.

 * Input/Output Statements: In JS, input is the process of receiving data from external resources and can be done by making a prompt letting the user input a value. Output on the other hand is the display/printing of the information entered achieved by writing text in the console using statements like "console.log".
